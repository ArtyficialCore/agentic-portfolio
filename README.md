# Agentic Workflow Architect - buduję autonomiczne systemy AI, które pracują za Ciebie, gdy Ty skupiasz się na tym, co ważne.

Filip, Poznań.

Pracuję analitycznie: najpierw rozkładam problem na decyzje architektoniczne, potem dobieram narzędzia do konkretnego celu. Trzymam pełną kontrolę nad tym, co dostarczam - rozumiem ograniczenia, ryzyka i koszt utrzymania każdego elementu. Vibe coding traktuję jako metodę pracy: Claude Code i Cursor piszą kod, a ja definiuję architekturę i biorę odpowiedzialność za każdą decyzję.
